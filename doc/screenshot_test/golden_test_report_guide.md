# Golden Test Report Guide

This document describes how to generate and use the two golden test HTML reports.

## Reports Overview

| Report | Purpose | Generated By |
|--------|---------|--------------|
| **Gallery Report** | Browse all golden screenshots with filters and comparison | `run_generate_loc_snapshots.sh` |
| **Verify Report** | View pass/fail results with failure image diff | `run_golden_verify.sh` |

Both reports are generated at `test/golden_test/` and reference images via relative paths.

---

## Gallery Report

### Generating

```bash
# Full run (generates goldens + gallery report)
./run_generate_loc_snapshots.sh -l "en,ja,zh" -s "480,1280" -v "1.0.0"

# Report-only (if goldens already exist)
dart run test_scripts/generate_gallery_report.dart [version]
```

Output: `test/golden_test/golden_gallery_report.html`

### Features

#### View Modes

- **Feature** (default) — Grouped by feature (e.g., dashboard, port_forwarding). Each section is collapsible.
- **Compare** — Same state grouped in a horizontal row across locales. Ideal for spotting text overflow or layout breakage in specific languages.

Switch modes via the **View** toggle in the toolbar.

#### Thumbnail Size

Use the **S / M / L** buttons to adjust the grid thumbnail size without opening individual images.

- **S** — High density overview, scan many images quickly
- **M** — Default balanced view
- **L** — Larger thumbnails for detailed inspection without lightbox

#### Search

Type in the search box to instantly filter by state name or feature name. Works in both Feature and Compare modes.

#### Filters

Checkbox filters for **Feature**, **Locale**, and **Device**. Uncheck to hide specific categories.

#### Lightbox

Click any image to open full-screen lightbox:

- **Left/Right arrow keys** — Navigate to previous/next image
- **Escape** — Close lightbox
- **Click dark background** — Close lightbox
- Position indicator shows: `feature (N/total) — state — locale / device`

Navigation scope respects current filters — only visible images are included.

## Verify Report

### Generating

```bash
# Full verification run
./run_golden_verify.sh -l "en,ja" -s "480,1280" -v "1.0.0"

# With embedded images (for CI, since golden PNGs are gitignored)
./run_golden_verify.sh -l "en" -s "480,1280" --embed
```

Output: `test/golden_test/golden_verify_report.html`

### Features

#### Test Summary Panel

Shows total / pass / fail counts with a donut chart.

#### Coverage Panel

Displays how many USP views have golden tests. Lists missing views in a collapsible section.

Coverage ignores these features (no golden tests needed): `apps`, `system_log`, `test_console`.

#### Quick Filter

- **All** — Show all test results
- **Failures Only** — Instantly hide passing tests to focus on what's broken

#### Group By

- **Feature** (default) — Grouped by feature directory. Failed features auto-expand. When multiple locales exist, failures are sub-grouped by locale to show if a specific language is broken.
- **Locale** — Grouped by locale. Useful to see if one language has widespread failures.

#### Search

Type to filter by test name or feature path. Combines with checkbox filters.

#### Failure Details

Each failed test shows:

1. **3-column comparison** — Expected / Actual / Diff side by side. Click any image to open in lightbox.
2. **Overlay slider** — Drag the slider left/right to blend between Expected and Actual. The left side shows Expected, right side shows Actual. This is the fastest way to spot pixel-level differences.
3. **Error message** — Raw test failure output in a scrollable code block.

#### Lightbox

Same keyboard navigation as Gallery Report. Caption shows position and test name with image type (Expected/Actual/Diff).

## Tips for QA

### Quick locale review workflow

1. Generate gallery with multiple locales: `-l "en,ja,de,th"`
2. Open gallery report, switch to **Compare** mode
3. Scan each row — all locales side by side, text overflow is immediately visible
4. Use **Size: L** for detailed inspection or **Size: S** to scan rapidly

### Investigating failures

1. Run verify: `./run_golden_verify.sh -l "en" -s "480,1280"`
2. Open verify report, click **Failures Only**
3. Use the **overlay slider** to compare Expected vs Actual
4. If diff is subtle, click the Diff image to open in lightbox for full resolution
