# Instant-Test Wiki

In-repo knowledge base for the Instant-Test customer WiFi diagnostic feature.
Travels with the code so it stays in sync across pushes.

**Start at [`index.md`](index.md).**

Structure (mirrors the Linksys Engineering Wiki schema):
- `index.md` — catalog, start here
- `overview.md`, `code-map.md`, `feature-linkage-map.md`, `roadmap.md`
- `concepts/` — architectural ideas (two-line strategy, design system, verdict engine)
- `processes/` — how-to (build & deploy, branch strategy)
- `reference/` — lookups (shared helpers, JNAP calls)
- `log.md` — change log

Conventions: `[[page-name]]` interlinks, lowercase-hyphen filenames, each page
carries a `Last Verified` date.
